<h1 align="center">Fuel Calculator</h1>

**Fuel Calculator** is a simple web application for bikers and drivers that estimates total fuel required and total fuel cost for their journey, So if you are at the fuel pump and want to know how much fuel and budget you will need for your trip quickly, then this [app](https://fuelcalculator.pages.dev/) is for you!

## Demo

[![Demo](https://img.youtube.com/vi/5vDlkPbRStE/maxresdefault.jpg)](https://youtu.be/5vDlkPbRStE)

## Features

- Calculates total fuel required based on distance and vehicle mileage
- Calculates total fuel cost based on fuel price and distance
- Supports multiple fuel types (Petrol, Gasoline, Diesel, CNG, Electric)
- Supports multiple distance units (Kilometers, Miles)
- Supports multiple currencies (INR, USD, EUR)
- User-friendly responsive design for quick access
- Validates user input to ensure correct data entry

## Setup

### 1. Clone the repository

    git clone https://github.com/karmaniket/Fuel-Calculator.git
    cd Fuel-Calculator

### 2. Deploy on Cloudflare

- Push your code to GitHub repository
- Create a new page under `Worker & Pages` on Cloudflare
- Connect your repository and deploy

### 3. How it works

- Simply select your preferred distance unit
- Enter the total trip distance
- Enter your vehicle's mileage
- Choose the fuel type you use
- Enter the current fuel price
- Select your currency
- Click on "Calculate" to get the total fuel required and total cost
